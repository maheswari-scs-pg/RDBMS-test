# CollegeDB - Department Table Assignment

## Objective
Create a database named **CollegeDB** and create a **Department** table with the required fields and constraints.

## Problem Statement

Create a database named `CollegeDB`.

Create a table named `Department` with the following attributes:

| Field Name | Data Type | Constraint |
|------------|-----------|------------|
| DepartmentID | NUMBER(5) | Primary Key |
| DepartmentName | VARCHAR(20) | - |
| HOD | VARCHAR(20) | - |


## Requirements

1. Create the database `CollegeDB`.
2. Select the database.
3. Create the Department table.
4. Set DepartmentID as the Primary Key.
5. Insert sample records.
6. Display all records from the Department table.
